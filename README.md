# 📞 Ticket Service System

## 📌 About the project

This project is a web application built with **React + Vite** for managing ticket-based customer service.
It simulates a system where users generate tickets and are called in order, suitable for places like stores, clinics, or service desks.

---

## 🚀 Technologies used

* React
* Vite
* React Router DOM
* TailwindCSS
* Text-to-Speech (voice announcements)

---

## ⚙️ Features

* Generate new ticket
* Display generated ticket
* Call screen for attendants
* Admin panel
* Voice announcement for tickets
* Page navigation

## 🧠 How it works

* The user generates a ticket
* The ticket is displayed on screen
* The call screen manages the order
* The system can announce tickets by voice
* The admin panel controls the service flow

---

## 📌 Notes
